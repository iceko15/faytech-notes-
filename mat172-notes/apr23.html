Parametric Equations and Projectile Motion

BIG IDEA

Transitioning from rectangular coordinates $(x, y)$ to parametric form allows us to express a position as a function of a third variable, usually time ($t$) or an angle ($\theta$). This enables us to define the direction of a path and model real-world movement, such as the flight of a ball, where horizontal and vertical positions are independent yet linked by time.

Exam Note: On the test, there is no table required for the graph. You just need to show the graph itself. However, understanding how to "plug and chug" values of $t$ is essential for accuracy.

KEY TERMS

  • Parameter: The independent variable (usually $t$) that defines both $x$ and $y$.
  • Eliminating the Parameter: The algebraic process of converting parametric equations back into rectangular form (one equation with $x$ and $y$ only).
  • Orientation: The direction in which the curve is traced as the parameter $t$ increases (indicated by arrows on the graph).
  • T-Step: The increment by which the calculator moves between points. Small steps make smooth curves; large steps make "blocky" graphs.

STEPS/PROCESS

1. Calculator Configuration

  • Mode: Set to PAR (Parametric).
  • Angle: Use Radian unless the problem explicitly uses degrees (common in projectile motion).
  • Window Settings:
    • $T_{min}$ and $T_{max}$: Define the interval provided in the problem.
    • $T_{step}$: If $t$ is an angle, use $\pi/24$, $\pi/12$, or $\pi/2$. If $t$ is a real number, try $0.1$ or $1$.

2. Eliminating the Parameter

  • Solve for $t$: Isolate $t$ in one equation (usually the simpler linear one).
  • Substitute: Plug the expression for $t$ into the other equation.
  • Simplify: Get the equation into a recognizable rectangular form (parabola, circle, etc.).
  • Restrict Domain: Because parametric graphs are often only portions of a shape, you must state the range of $x$ values that correspond to the $t$ interval.
Pro-Tip: If you see sines and cosines, don't use substitution. Use the Pythagorean identity $\sin^2(t) + \cos^2(t) = 1$ to force the equation into the standard form of a circle or ellipse.

RULES/IDENTITIES

  • Pythagorean Identity: $\sin^2(t) + \cos^2(t) = 1$
  • Circle Template: $(x - h)^2 + (y - k)^2 = r^2$
  • Ellipse Template: $x = h + a\cos(t)$, $y = k + b\sin(t)$
  • Projectile Motion Template:
    • $x = (v_0 \cos \theta)t$
    • $y = h + (v_0 \sin \theta)t - 16t^2$

EXAMPLE 1: Parabolic Path

Given: $x = t + 2$, $y = t^2$ on the interval $-2 \le t \le 2$.

Graphing:
  • At $t = -2$: $x=0, y=4 \rightarrow (0, 4)$
  • At $t = 0$: $x=2, y=0 \rightarrow (2, 0)$
  • At $t = 2$: $x=4, y=4 \rightarrow (4, 4)$
Eliminating Parameter:
  1. Solve $x = t + 2$ for $t$: $t = x - 2$.
  2. Substitute into $y$: $y = (x - 2)^2$.
  3. Identify shape: Parabola with vertex at $(2, 0)$.
  4. Domain Restriction: Since $t$ was $[-2, 2]$, $x$ only goes from $0$ to $4$. Domain: $[0, 4]$.

EXAMPLE 2: Trig-Based Circle

Given: $x = 2\sin(t)$, $y = 2\cos(t)$ for $0 \le t \le 2\pi$.

Method: Pythagorean Identity
  1. $\frac{x}{2} = \sin(t)$ and $\frac{y}{2} = \cos(t)$.
  2. $(\frac{x}{2})^2 + (\frac{y}{2})^2 = \sin^2(t) + \cos^2(t)$.
  3. $\frac{x^2}{4} + \frac{y^2}{4} = 1$.
  4. $x^2 + y^2 = 4$.
Result: A circle centered at $(0, 0)$ with radius $2$.
Distortion Warning: The calculator screen is wider than it is tall. A perfect circle often looks like an oval (ellipse). Use Zoom Square to see the true shape.

EXAMPLE 3: Projectile Motion (Real-World)

Scenario: Ball launched at $v_0 = 160$ ft/s, angle $\theta = 35^\circ$, from height $h = 3$ ft.
  1. Equations: $x = (160 \cos 35^\circ)t$
    $y = 3 + (160 \sin 35^\circ)t - 16t^2$
  2. Flight Time: Set $y = 0$ and use the Quadratic Formula to solve for $t$. $$t = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$$ (Ignore the negative $t$ value).
  3. Horizontal Distance: Plug the positive flight time $t$ back into the $x$ equation.

SUMMARY

Parametric equations allow us to separate horizontal motion from vertical motion. When graphing, always pay attention to the interval of $t$ to avoid graphing the entire shape when only a piece is needed. When eliminating the parameter, use substitution for polynomials and trigonometric identities for periodic functions.
